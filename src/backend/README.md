**Environmental variables**

- `PORT` - Port on which the server is hosted. Default is `3000`.
- `CLIENT_URL` - URL on which the frontend part is hosted. Can be left blank during development.
- `JWT_SECRET` - Secret key for JWT tokens.
- `DB_PATH` - Path to the SQLite database file. Path is relative to the running directory.
- `DEFAULT_ADMIN_EMAIL` - Email address for the default administrator account. Default is `admin@saxion.nl`.
- `DEFAULT_ADMIN_PASSWORD` - Password for the default administrator account. Default is `password`.
